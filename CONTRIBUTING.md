# Contributing

Keep merchant operation no-code, preserve queue idempotency and minimize order
data. Never log tokens or customer records.

1. Open an issue for large behavioral changes.
2. Run `npm run lint` and `npm run test:native`.
3. Describe PrestaShop versions tested and privacy impact in the pull request.
4. Update `CHANGELOG.md` for user-visible behavior.

Contributions are accepted under AFL-3.0.
